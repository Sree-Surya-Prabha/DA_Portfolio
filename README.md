## 🚀 How to Host on Vercel

### Method 1: Deploy via GitHub (Recommended — 2 Minutes)

1. **Push this folder to a new GitHub repository**:
   ```bash
   git add .
   git commit -m "Initial commit: Professional Data Analyst Portfolio"
   git branch -M main
   git remote add origin https://github.com/Sree-Surya-Prabha/portfolio.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **"Add New..."** → **"Project"**.
4. Select your `portfolio` repository and click **"Import"**.
5. Leave all build settings as default (Framework Preset: *Other*, Root Directory: `./`).
6. Click **"Deploy"**.
7. Vercel will build and assign your free live URL (e.g., `https://sree-surya-prabha-portfolio.vercel.app`) in under 30 seconds!

---

### Method 2: Deploy via Vercel CLI

1. In this project directory, run:
   ```bash
   npx vercel
   ```
2. Follow the on-screen prompts:
   - Log in or authenticate in browser.
   - Set up and deploy `c:\Users\Teju\OneDrive\Desktop\Sure Trust`? → **Y**
   - Which scope? → Select your personal account.
   - Link to existing project? → **N**
   - What's your project's name? → `sree-portfolio`
   - In which directory is your code located? → `./`
3. Done! To deploy to production:
   ```bash
   npx vercel --prod
   ```
